Aplus Digitizing is the web presence for an embroidery digitizing and vector art company that converts customer artwork into machine-readable embroidery files and scalable vector graphics. It serves embroidery shops, screen printers, and apparel businesses that need production-ready file conversions. Built as a fast single-page React application with smooth motion-driven UI and client-side data fetching for quotes and orders.
Technologies: React, Vite, TanStack Query, Framer Motion
