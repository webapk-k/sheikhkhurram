Aurelle is a beauty and spa website built in WordPress around the block editor rather than a page builder. Every homepage section — hero, about, services, marquee, appointment band, price list, gallery, booking, therapists, journal and testimonials — is a server-rendered Gutenberg block listed in the inserter under “Aurelle sections”, so the front page is an ordinary page an editor can rearrange by dragging. Content lives where it belongs: treatments and therapists are custom post types with their own archives, grouped by a taxonomy the salon controls, with Advanced Custom Fields declared in code for price, duration, icon, role, qualification and years in practice — edit a treatment once and it changes everywhere it appears. The palette, type scale and spacing sit in theme.json, so the editor only ever offers on-brand choices. The booking form is validated and sanitised server-side, protected by a honeypot and a rate limit, and records each request before emailing it, so nothing is lost if mail fails. Motion runs on self-hosted GSAP ScrollTrigger and Lenis smooth scrolling driven from a single ticker, the off-canvas mobile menu degrades to a plain list without JavaScript, and 67 checks run over real HTTP — including the requests the booking endpoint should refuse. The public link is a static snapshot on Cloudflare Workers: everything browses and animates, while booking and search run on the full PHP installation.
Technologies: WordPress, Gutenberg Blocks, ACF, Custom Theme, PHP, theme.json, GSAP, Lenis, Cloudflare Workers
