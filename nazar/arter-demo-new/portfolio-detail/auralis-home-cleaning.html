Auralis Home Cleaning

Back to Portfolio
Auralis is a home-cleaning company’s site where booking actually runs on automation instead of a contact form. A custom WordPress theme carries the dark, motion-led front end — GSAP with ScrollTrigger and Lenis smooth scrolling — and a purpose-built plugin does the work behind it through five REST endpoints: an AI assistant that answers from the business’s own knowledge base, a rules-based rate card that prices a clean, real free slots read from the calendar, the booking itself, and a handover route to a human when the assistant should stop guessing. Chat, the booking form and the phone all feed the same pipeline, so a confirmed visit is saved as a record, relayed to n8n by webhook in a Google-Sheets-ready payload, synced to Google Calendar and confirmed by email, with a daily follow-up job and an owner dashboard for bookings and leads. The site around it carries the services and rates, an instant quote calculator, an FAQ, service areas and a booking page that takes the service, room count, add-ons, date and slot. The public link is a static snapshot: every page, the layout and the motion are all there, while the assistant, quotes, live slots and booking run on the full WordPress installation.
Technologies: WordPress, Custom Theme, Custom Plugin, PHP, REST API, OpenAI, n8n Webhooks, GSAP, Lenis, Cloudflare Workers
